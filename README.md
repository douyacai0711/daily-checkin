# 个人每日打卡

无需安装依赖的静态网站，包含递增间隔打卡、下次可打卡日期、剩余天数、累计次数、月历和最近七条记录。

首次可立即打卡。第 1 次完成后隔 1 天，第 2 次完成后隔 2 天，第 3 次完成后隔 3 天，以此类推，无间隔上限。例如在 10 月 5 日首次打卡，后续最早可打卡日期依次为 10 月 6 日、10 月 8 日、10 月 11 日。

间隔按本地日历日期计算，到期当天即可打卡；提前打卡会被阻止。同一天最多记录一次。错过日期后仍可打卡，下次日期从实际打卡日计算，不会自动重置进度。已有记录保持不变，每条已有记录计入累计次数和间隔阶段，例如已有 3 条记录时，下次日期为最近一次打卡日加 3 天。

记录存在浏览器 localStorage 中。同一天重复点击不会增加记录，日期按设备时区计算。不同设备、浏览器和网站地址之间不会同步数据，清除网站数据会删除记录。

## 本地预览

在此目录运行 `python -m http.server 8765 --bind 127.0.0.1`，打开 http://127.0.0.1:8765。

## 发布到 GitHub Pages

1. 创建公开的 GitHub 仓库。
2. 将本目录中的 `index.html` 上传到仓库根目录。
3. 打开仓库 Settings → Pages。
4. Source 选择 Deploy from a branch，Branch 选择 main，目录选择 / (root)，点击 Save。
5. 等待发布完成，访问 Pages 页面显示的网址。

此版本没有登录、数据库或服务器，不需要 API 密钥。在线地址与本地预览各自保存独立记录。

## 验证

安装 Node.js 后运行 `node --test tests/checkin.test.cjs`。测试覆盖递增间隔、提前及重复打卡、逾期打卡、跨月跨年、闰年、已有记录和存储失败。
